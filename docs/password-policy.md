# Política de senhas

Profissionais, donos de academia, centros de treinamento e coaches usam a
política forte: oito caracteres, maiúscula, minúscula, número e símbolo.

Alunos criados pelo coach usam somente o mínimo de seis caracteres para evitar
bloqueio durante o cadastro. Essa diferença é coberta por testes unitários.
